# 📚 BookStore Client – Front-end

Interface web do sistema **Projeto Final De Programação WEB**, desenvolvida como uma SPA (Single Page Application) utilizando **React + TypeScript + Vite**.

A aplicação consome a API REST desenvolvida em Spring Boot.

---

## ✨ Funcionalidades

### 🛍️ Catálogo

✔️ Listagem de livros
✔️ Paginação por categoria
✔️ Cards com imagem, preço e botão de compra
✔️ Página individual do livro com galeria e descrição

### 👤 Autenticação

✔️ Cadastro de usuário
✔️ Login
✔️ Logout
✔️ Validação de formulários

### 🛒 Carrinho

✔️ Adicionar e remover itens
✔️ Controle de quantidade
✔️ Totais automáticos
✔️ Persistência com LocalStorage

### 💳 Checkout

✔️ Página de finalização de compra
✔️ Seleção de endereço
✔️ Confirmação de pedido

### 📦 Área do Cliente

✔️ Histórico de compras
✔️ Cadastro de endereço
✔️ Página de endereços cadastrados

## ▶️ Como Executar

### 📌 Pré-requisitos

* Node.js
* npm

### 📥 Clonar o repositório

```bash
git clone https://github.com/Rafaela0203/DeluxClient-PW44S.git
cd DeluxClient-PW44S
```

### 📦 Instalar dependências

```bash
npm install
```

### ▶️ Executar aplicação

```bash
npm run dev
```

A aplicação estará disponível em:

```
http://localhost:5173
```

## 🎯 Objetivo

Desenvolver uma interface moderna, responsiva e componentizada para um E-Commerce de livros, aplicando boas práticas de desenvolvimento front-end e integração com API REST.
